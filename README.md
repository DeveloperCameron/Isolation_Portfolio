# Isolation — Brand Landing Page
 
A fully responsive landing page for **Isolation**, an independent clothing brand. Built from scratch with a dark, minimal editorial aesthetic — no templates, no frameworks, just clean HTML and CSS.
 
🔗 **Live Site:** [developercameron.github.io/Isolation_Portfolio](https://developercameron.github.io/Isolation_Portfolio/)
 
---
 
## Overview
 
This is a real business landing page, not a tutorial project. Isolation is a clothing brand I founded — this site is its digital presence. The goal was to create something that felt premium and intentional with nothing but vanilla HTML and CSS.
 
---
 
## Built With
 
- HTML5 (semantic markup)
- CSS3 — Flexbox, Grid, custom keyframe animations
- Vanilla JavaScript — scroll effects, nav behavior
- Google Fonts — Bebas Neue, DM Sans
- Deployed on GitHub Pages
---
 
## Features
 
- Full-screen hero with large display typography and ghost outline text
- Scrolling marquee ticker — CSS animation, no JS library
- Product showcase grid with hover overlays
- About section with brand ethos and stats
- Waitlist form with client-side success state
- Scroll-reveal animations using IntersectionObserver
- Fully responsive — built mobile-first
---
 
## Design Decisions
 
| Decision | Reasoning |
|---|---|
| Dark background (#0a0a0a) | Conveys premium, minimal streetwear aesthetic |
| Bebas Neue display font | High-impact editorial headlines — industry standard in fashion |
| Acid green accent (#c8ff00) | Single accent color creates tension against the dark palette |
| Ghost/outlined text | Creates depth and visual interest without adding elements |
| Crosshair cursor | Reinforces the intentional, brand-aware design language |
